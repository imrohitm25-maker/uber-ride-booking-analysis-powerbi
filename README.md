# 🚖 Uber Ride Booking Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing Uber ride-booking data using Microsoft Power BI. The dashboard provides insights into booking performance, revenue trends, vehicle-wise performance, and ride outcomes through interactive visualizations.

## 🎯 Project Objectives
- Analyze total and completed ride bookings.
- Track successful, cancelled, and lost bookings.
- Understand revenue trends over time.
- Compare booking and revenue performance across vehicle categories.
- Identify patterns that can support data-driven business decisions.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Data Analysis** – Performance tracking and trend analysis

## 📊 Key Features
- **Booking Analysis:** Understand total bookings and booking status.
- **Revenue Analysis:** Analyze revenue patterns across different periods.
- **Vehicle Analysis:** Compare performance across vehicle categories.
- **Trend Analysis:** Explore booking trends over time.
- **Interactive Dashboard:** Use filters and slicers to explore the data.
